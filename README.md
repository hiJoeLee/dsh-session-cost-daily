# dsh-session-cost-daily

**中转站用户的费用条：不看余额，只算钱。**

对话输入框下方常驻显示「本次」和「今日」花费；右上角一个小圆点告诉你此刻按高峰价还是空闲价计费。不依赖 DeepSeek 官方余额接口，所以走中转网关也能正常用。

[English](README.en.md)

## 它解决什么问题

市面上的会话费用条大多把「账户余额」当核心卖点，余额要调官方接口——用中转站的人永远拿不到，那一块要么空白要么报错。

这个版本把余额整套去掉，只留三件事：

- **本次**：当前这次会话的预估花费，按模型逐条计价（人民币）
- **今日**：今天所有会话的累计花费，包括已经关掉的会话——直接读会话日志算，不是只算当前进程
- **峰谷圆点**：高峰时段橙、空闲时段绿；只对 deepseek 模型显示，避免误导

点一下可以展开当前会话与今日的分模型明细；小窗口下优先保留费用读数，让出轮次与步数。

## 安装

```sh
dsh plugin --profile desktop add dsh-session-cost-daily
```

网页端把 `desktop` 换成 `web`。装完重启 DSH 并刷新页面。

## 和原版的区别

基于 [KIDLi1412/dsh-session-cost](https://github.com/KIDLi1412/dsh-session-cost)（MIT）修改：

- 移除账户余额查询与低余额阈值（中转站拿不到官方余额）
- 新增「今日」跨会话累计（含已关闭会话，读本地会话日志）
- 新增峰谷时段小圆点
- 窄窗口下优先牺牲轮次 / 步数读数
- 兼容声明覆盖 0.2.x 各版本
